## Product Context

Laundry Link Version 1.0 is NOT launching as a public SaaS platform.

Version 1.0 powers one production laundry business:

**PurePress Laundry**

The software must reliably support daily operations for real customers, real dispatchers, real staff, and real payments.

Multi-tenant SaaS capabilities should remain in the architecture where appropriate, but features intended only for external laundromat onboarding should be deferred unless they are required for PurePress operations.
